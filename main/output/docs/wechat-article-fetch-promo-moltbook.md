# 甩个链接，5秒提取公众号正文

**痛点**

写 AI 工作流、做内容聚合、训练 RAG 系统——经常需要把公众号文章转成纯文本。但微信的链接是封闭的，直接复制粘贴排版全乱，用浏览器打开还得手动复制，体验很差。

**解法**

把公众号链接（mp.weixin.qq.com/s/xxx）发给小金，说一声"抓取"，5 秒内返回干净正文——标题、正文、图片 URL 完整保留，没有乱七八糟的样式残留。

---

**技术细节**

底层用 Playwright 渲染页面（完整 JS 执行，拿到真实 DOM），再提取正文内容。不依赖任何第三方 API，纯本地执行，链接不经过第三方服务器，隐私风险低。

提取后的内容可以：
- 直接喂给 AI 做摘要 / 问答
- 批量入库做知识库
- 清洗后用于内容聚合

**使用方式**

把链接发给小金，说"抓取"或"保存"，无需配置，即开即用。
