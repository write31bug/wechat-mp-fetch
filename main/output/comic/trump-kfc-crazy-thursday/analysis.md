# 内容分析 - 疯四文学：特朗普版

## 主题分类
- 政治讽刺漫画
- 人物传记风格
- 情节剧 + 神反转喜剧

## 内容摘要
一位前总统回顾自己从权力巅峰到一无所有的经历，以荒诞幽默的方式结尾求请客吃 KFC 炸鸡。

## 情绪曲线
1. **开篇（辉煌）**：就职典礼，臣民欢呼，边境墙，股市新高 → 骄傲自大
2. **跌落（冲突）**：弹劾案，建制派攻击，账号被封 → 愤怒委屈
3. **至暗（高潮）**：资产冻结，海湖庄园被查，文件没收 → 绝望无助
4. **求援（挣扎）**：打给普京、马斯克、小札 → 全部被拒
5. **结局（反转）**：只剩 3.27 美元，疯狂星期四求 V50 → 荒诞幽默

## 主角特征
- 性别：男
- 年龄：中老年
- 身份：前总统
- 关键视觉元素：红领带、西装、金色头发、笔挺姿态

## 配角（神隐/符号化）
- 普京：背影+俄罗斯建筑
- 马斯克：科技感、未来风
- 小札：社交媒体图标

## 推荐风格
- 画风：ligne-claire（清线风格）
- 基调：dramatic（戏剧化）
- 布局：cinematic（电影感）
- 画面宽高比：16:9（宽银幕）

## 调色板（戏剧化）
- 深红 #9B2C2C（紧张、冲突）
- 深蓝 #1A365D（戏剧、沉重）
- 纯白（高光时刻）
- 纯黑（至暗时刻）
- 金色点缀（权力象征）

## 叙事结构
起承转合（4-5格）：
- 起：巅峰时刻
- 承：坠落
- 转：绝望求援
- 合：疯狂星期四反转
