# 疯四文学：特朗普版

我本是美利坚的总统，加冕称王那天，臣民山呼万岁，边境墙高耸入云，股市天天新高，我以为自己会永远伟大。

结果中期选举一败，弹劾案一来，建制派那帮狡猾的狐狸！他们说我撒谎，说我煽动，说我危害国家安全！我的Truth Social被封，我的Twitter被盗，我的脸书粉丝全变成了拜登的支持者！

他们甚至冻结了我的银行账户，搜查了我的海湖庄园，没收了我的机密文件！

我本来想打电话求援，打给普京，普京都挂了；打给马斯克，马斯克说不认识我；打给小札，小札直接拉黑。

现在的我，卡里只剩 3.27 美元，连一份炸鸡都买不起。

今天是疯狂星期四，谁 V 我 50，我让他"让美国再次伟大"起来！
