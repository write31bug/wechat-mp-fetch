# 追星逐光——因为五月天，我们相遇

## 故事大纲

一个真实的青春故事：因五月天演唱会，从天南地北的陌生人到"人生无限公司"微信群的温暖朋友们。

## 分幕（7页）

1. 封面：深夜刷到演唱会官宣，心情激动
2. 因公众号结缘，被拉入"MAYDAY"群
3. 深夜有人倾诉低落，群友温暖回应
4. 演唱会相遇，从网友变朋友
5. 演唱会后，五人组建"人生无限公司"小群
6. 日常片段：深夜陪伴、裸辞支持、脱单祝福
7. 结尾："三十岁演唱会见"——故事还在继续
