# 第4页：老公变香料包

**场景：** 君姐惊恐地看着老公——老公的脑袋变成了一个巨大的十三香料包，上面还印着婆婆（约55岁，笑眯眯的老奶奶）的笑脸，料包上写着"特浓十三香，祖传配方"。

**文字气泡（君姐，惊恐）：** "你的头……变成那个了！"

**文字气泡（香料包老公，声音是婆婆）：** "加点十三香……更香……"

**画风：** Japanese manga, horror-comedy, surreal body horror, man head replaced by giant spice package with grandma's smiling face, dramatic panel, comedy manga style
