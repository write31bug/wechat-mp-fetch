# 第3页：幻觉发作

**场景：** 君姐在家中客厅，眼前开始出现幻觉——地毯上爬满指甲盖大小的金色蝎子，窗帘的流苏变成了吐着信子的蛇，吊灯变成了巨大的十三香料包。整体色调扭曲，偏向诡异。

**文字气泡（君姐，惊恐）：** "这……是什么……"

**旁白文字：** 君姐吃了两块排骨，回家路上就觉得眼前发飘。

**画风：** Japanese manga, horror-comedy, surreal distorted perspective, golden scorpions on floor, snake-like curtain fringes, giant spice package chandelier, eerie warm tones, dramatic manga panels
