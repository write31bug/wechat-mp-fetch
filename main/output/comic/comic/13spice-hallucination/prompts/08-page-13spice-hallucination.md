# 第8页：结尾彩蛋

**场景：** 君姐回到自己家，瘫坐在沙发上，疲惫不堪。她老公端着一个小碗走过来，碗里是清汤挂面。君姐的筷子慢慢伸向旁边的那碟十三香调料……

**文字气泡（老公，平静）：** "老婆，我妈说让你明天再去吃饭。"

**最后一格特写：** 君姐夹起一小撮十三香放进嘴里，脸上开始出现恍惚的表情……天花板的灯罩上浮现婆婆的笑脸。

**文字气泡（幻觉婆婆）：** "加点十三香，更香……"

**黑底白字：** 十三香

**画风：** Japanese manga, horror-comedy ending, dramatic irony, suspenseful final frame, dark screen with logo, comedy horror manga style
