- 测试后发现官方 `wecom-openclaw-plugin` 多 Bot 路由有 bug

### Bug 确认
- 根因：OpenClaw framework `pi-embedded-helpers` 的 `resolveSessionKey` 硬编码 `DEFAULT_AGENT_ID`，不看 bindings
- 症状：多 Bot DM 全路由到 default agent，不是各自绑定的 agent
- 同类问题也存在于 Feishu 插件（GitHub Issue #8692）
- 链接：https://github.com/openclaw/openclaw/issues/8692
- 已投票 ✅

### 解决方案
- **sunnoy/openclaw-plugin-wecom**（社区增强版）：原生支持多账号 + Bindings 路由
  - npm: `@sunnoy/wecom`
  - 安全评估：🟡 MEDIUM（可装，非官方）
  - 当前不急，等官方修好再装
- **回滚**：删除了 wecom 配置，恢复原状
