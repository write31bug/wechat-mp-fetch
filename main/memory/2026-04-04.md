### DesktopCal 日历清单集成
**背景**：金哥不用企业微信了，改用 DesktopCal（桌面日历）管理个人待办。

**定位**：
- CalendarTask 日历清单 = 金哥个人"应该做什么"的记录
- board.db 看板 = 团队任务流转中枢
- 两者独立，互补替代

**数据库路径**：`C:\Users\Administrator\AppData\Roaming\CalendarTask\Db\calendar.db`
- `item_table`：存储每日待办（`dkcal_mdays_YYYYMMDD` UID = 当天条目）
- 内容格式：多行文本，`[+] 前缀` = 已完成状态
- `it_history`：JSON 历史记录

**技术关键发现**：
- DesktopCal widget（dkdockhost）有内存缓存，直接 SQL 写入后不自动刷新
- 必须重启 desktopcal 主程序才能让 widget 重新读数据库
- Widget 渲染时 `[+]` 前缀会被隐藏（正常行为）

**脚本**：`E:\openclaw\main\scripts\desktopcal_todo.py`
```
python desktopcal_todo.py add <任务>         # 添加
python desktopcal_todo.py list               # 查看
python desktopcal_todo.py done <行号>       # 标记完成
python desktopcal_todo.py del <行号>        # 删除
python desktopcal_todo.py modify <行号> <新内容>  # 修改
```
