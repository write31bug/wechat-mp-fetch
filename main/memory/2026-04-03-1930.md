assistant: The user is asking if each tool needs a separate MCP server. This is a good question about the architecture of Agent Reach.

From what I've seen:
- **Exa** has its own MCP server (`https://mcp.exa.ai`)
- **Douyin** would need `douyin-mcp-server` (local)
- **WeChat** uses camoufox (not MCP)
- **Xiaohongshu** uses xhs-cli (not MCP)
- **Xueqiu** uses direct HTTP calls (not MCP)

So the answer is: **No, not every tool needs a separate MCP**. Agent Reach uses multiple approaches:
1. **MCP servers** for some tools (Exa, Douyin, etc.)
2. **CLI tools** for others (xhs-cli, yt-dlp, etc.)
3. **Direct HTTP/API calls** for others (Xueqiu, V2EX, etc.)

The MCP approach is just one way to integrate tools, used when it makes sense (like for Exa's semantic search). Many tools work fine with CLI or direct API calls.不是每个工具都需要单独的 MCP。

Agent Reach 用三种方式集成工具：

**1. MCP 服务器（少数）**
- Exa 搜索 → `https://mcp.exa.ai`（远程）
- 抖音 → `douyin-mcp-server`（本地，需安装）

**2. CLI 工具（多数）**
- 小红书 → `xhs-cli`
- YouTube/B站 → `yt-dlp`
- 微博/V2EX → 直接 curl

**3. 直接 HTTP 调用（部分）**
- 雪球 → 直接 Python requests
- RSS → feedparser

---

**MCP 的优势**：标准化接口，适合复杂工具  
**CLI/HTTP 的优势**：轻量，无需额外服务

所以抖音需要装 `douyin-mcp-server` 才能用，但其他工具大多不需要。要装抖音 MCP 吗？
