## 📝 任务护照填写规范

**5个必填字段：**
- `task_id`：T+序号，如 T002
- `context`：背景 + 目标 + 约束条件
- `assignee`：当前负责人
- `status`：PENDING / IN_PROGRESS / BLOCKED / DONE / CANCELLED
- `next_step`：下一步交给谁、要做什么

**填写时机：**
- 任务开始前：填 task_id + context + assignee（由小金填写）
- 状态变更时：更新 status + next_step（执行者填写）
- 任务完成时：补完所有字段，标记 DONE
