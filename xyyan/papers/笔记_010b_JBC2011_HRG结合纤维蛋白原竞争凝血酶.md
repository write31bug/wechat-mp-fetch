---

## 一、研究背景

- HRG可结合纤维蛋白原和其他血浆蛋白，但具体结合位点和功能不明
- 已知HRG掺入纤维蛋白凝块可促进细菌截获和炎症反应
- **关键问题**：HRG与纤维蛋白原相互作用的分子基础是什么？与凝血酶的关系如何？

---

## 二、主要结果

### 2.1 HRG与纤维蛋白原的高亲和力结合

| 参数 | 数值 |
|------|------|
| 结合条件 | Zn²⁺存在 |
| 结合对象 | γA/γA-纤维蛋白原 和 γA/γ'-纤维蛋白原 |
| 解离常数(Kd) | **~9 nM**（高亲和力） |
| 结合形式 | HRG-纤维蛋白原复合物在循环中存在，并持续至纤维蛋白形成 |

### 2.2 结合位点：多个位点，位于D区和E区

- HRG可结合纤维蛋白原的**D片段**或**E片段**
- HRG还结合**γ'肽**（γ'链的C端，类似物）
- γ'肽是介导凝血酶高亲和力结合于γA/γ'-纤维蛋白的关键区域

### 2.3 HRG与凝血酶竞争结合γ'-链

**竞争关系**：
- 凝血酶的exosite 2结合γ'-链的C端
- HRG同样结合γ'-肽
- **凝血酶和HRG互相竞争**：凝血酶可置换HRG，HRG也可置换凝血酶

### 2.4 机制意义

```
HRG + 纤维蛋白原 ──→ HRG-纤维蛋白原复合物
                    ↓ + Zn²⁺ + 凝血酶
              竞争γ'-链结合位点
                    ↓
         凝血酶结合↓ 或 HRG结合↓
                    ↓
         调节凝血/保护纤维蛋白凝块免受过度降解
```

---

## 三、核心机制总结

- HRG与凝血酶**竞争**结合于γA/γ'-纤维蛋白/纤维蛋白
- 这是HRG调节凝血的**新机制**（不同于已知的FXII抑制途径）
- HRG-纤维蛋白原复合物的形成可能影响：
  1. 凝血酶在纤维蛋白凝块上的定位
  2. 局部抗凝与促凝的平衡
  3. 与#003 PDI-HRG的构象调控机制相互补充

---

## 四、与苗姐课题的关联

1. **脓毒症相关凝血病**: HRG-凝血酶竞争机制为脓毒症凝血失衡提供新的分子解释
2. **DIC**: 凝血酶过度激活是DIC核心，HRG竞争性调节可能是保护机制之一
3. **与#003 PDI-HRG的关系**: PDI切割HRG二硫键改变构象，可能影响HRG与γ'-链的结合能力
