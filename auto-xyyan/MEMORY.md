## 🧬 四条核心机制轴（供课题设计参考）

### 轴1：H3K18la 乳酸酰化 → Egr1 → Heparanase → 糖萼降解
- 来源：Adv Sci 2024（IF>15）
- 完整链条：糖酵解↑ → 乳酸↑ → H3K18la → Egr1转录↑ → Heparanase激活 → HS降解 → 糖萼破坏 → 凝血激活
- **课题空白**：尚未系统延伸至 SIC/DIC，是创新切入点

### 轴2：Eno1 — 代谢 ↔ 内皮糖萼 ↔ 凝血 三交汇节点
- 来源：Thrombosis J 2025
- Eno1↑ → 糖酵解↑ + 乳酸↑ → H3K18la（间接）→ 糖萼损伤 + T细胞/巨噬细胞浸润
- 与轴1自然衔接，可作为课题假设起点

### 轴3：NETosis / CIT-HIST-H3 / 免疫血栓
- 来源：Sci Reports 2025、Front Immunol 2025
- CIT-HIST-H3 比 MPO 更特异；δ表型脓毒症凝血标志物最高
- 空白：缺乏 NET 特异标志物与 DIC 临床预后的系统研究

### 轴4：糖萼损伤标志物包（SDC-1、HS、HA）
- 来源：MedComm 2025、Front Med 2025、Clin Practice 2025
- 糖萼降解 → TF暴露↑ → 凝血激活（SIC/DIC 上游触发）
- 多篇确认外周血 SDC-1、HS 可及性强，适合临床样本研究
