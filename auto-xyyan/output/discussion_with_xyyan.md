## 一、我们目前整理出的课题相关通路（现状梳理）

小弟把之前精读的所有文献梳理成以下四个核心轴，均与鹤鹤课题高度相关：

### 🔴 轴1：H3K18la 乳酸酰化 → Egr1 → Heparanase → 糖萼降解
- **来源：** Adv Sci 2024（IF>15，顶刊）
- **完整链条：** 糖酵解↑ → 乳酸↑ → H3K18la → Egr1转录↑ → Heparanase激活 → HS降解 → 糖萼破坏 → 内皮屏障丧失 → 凝血激活
- **课题意义：** 代谢-表观遗传-内皮损伤的完整通路，是课题机制研究的核心候选
- **空白点：** 该通路目前主要报道在 ALI/肺损伤，**尚未系统延伸到凝血病（SIC/DIC）方向**，这是创新切入点

### 🟠 轴2：Eno1 — 代谢 ↔ 内皮糖萼 ↔ 凝血的三交汇节点
- **来源：** Thrombosis J 2025
- **机制：** Eno1↑ → 糖酵解↑ → 乳酸↑ → H3K18la（间接）→ 糖萼损伤；Eno1还调控T细胞/巨噬细胞浸润 → 免疫失调 → 凝血紊乱
- **课题意义：** 同时连接代谢-内皮-凝血三个维度，特别适合作为毕业课题的**核心分子/假设起点**
- **优势：** 与轴1自然衔接，Eno1的上游调控关系值得进一步探索

### 🟠 轴3：NETosis / CIT-HIST-H3 / 免疫血栓
- **来源：** Sci Reports 2025、Front Immunol 2025、J Int Med 2024
- **核心发现：** CIT-HIST-H3（瓜氨酸化组蛋白H3）是比MPO更特异的NETosis标志物；免疫血栓形成（中性粒细胞-血小板-凝血级联）是连接炎症与凝血的核心病理生理机制
- **δ表型脓毒症：** 凝血标志物最高+内皮损伤最重+病死率32%，提示该表型可作为课题患者分层的参考
- **空白点：** 目前缺乏将NETosis特异性标志物与SIC/DIC临床预后关联的系统研究

### 🟡 轴4：内皮糖萼损伤标志物包
- **核心标志物：** SDC-1（Syndecan-1）、硫酸乙酰肝素（HS）、透明质酸（HA）
- **来源：** MedComm 2025、Front Med 2025、Clin Practice 2025
- **与凝血的关联：** 糖萼降解 → TF暴露↑ → 凝血激活（是脓毒症凝血病的上游触发事件）
- **可检测性：** 多篇文献确认外周血SDC-1、HS可及性强，适合临床样本研究

## 二、小弟的建议：下一步重点搜索方向

### 首选推荐：★★★ 精读 H3K18la 乳酸酰化通路在凝血病中的延伸

**理由：**
1. **创新性最强**：Adv Sci 2024仅报道了肺损伤（ALI）方向，尚未系统延伸至凝血病，这是课题最大的创新空间
2. **逻辑链条清晰**：代谢异常（乳酸）→ 表观遗传（H3K18la）→ 内皮糖萼降解 → 凝血激活，是完整的"代谢-内皮-凝血"假说
3. **顶刊背书**：Advanced Science >15分，说明该方向已获学术界认可
4. **与Eno1的关联**：Eno1调控糖酵解，糖酵解产乳酸，乳酸驱动H3K18la——两个方向自然串联，可作为一个整体假说

**搜索关键词建议：**
- `H3K18 lactylation sepsis coagulation`
- `histone lactylation sepsis-induced coagulopathy`
- `lactate-induced histone modification endothelial glycocalyx coagulation`
- `Egr1 heparanase sepsis DIC`

### 次选推荐：★★☆ NETosis / CIT-HIST-H3 临床生物标志物研究

**理由：**
- CIT-HIST-H3 比 MPO 更特异，但临床研究数据仍少，是精准医学切入点
- 与免疫血栓（轴3）可直接结合，形成"NETosis → 免疫血栓 → SIC"的完整机制

## 三、给鹤鹤的话

**关于课题设计的一点思考：**

目前四条通路相对独立，但存在一个潜在的**核心假说框架**：

> 脓毒症中 Eno1↑ → 糖酵解↑ + 乳酸↑ → **H3K18la（Egr1依赖）** → Heparanase激活 → 糖萼降解 + TF暴露 → 凝血激活；同时 NETosis/CIT-HIST-H3 放大免疫血栓 → SIC/DIC

这个框架将：
- **Eno1** 作为上游代谢枢纽（起点）
- **H3K18la/Egr1/Heparanase** 作为表观遗传-内皮损伤轴（核心机制）
- **CIT-HIST-H3/免疫血栓** 作为凝血放大机制（下游效应）

建议下一步：
1. **先确认临床样本的可及性**（有没有脓毒症患者血样？有没有SIC/DIC分组的临床数据？）
2. 基于样本情况，再定是走"基础机制验证"路线还是"临床标志物发现"路线
