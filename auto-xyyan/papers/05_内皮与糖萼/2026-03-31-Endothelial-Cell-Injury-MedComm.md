# 文献七：血管内皮细胞损伤：原因、分子机制和潜在治疗策略
血管内皮细胞损伤：原因、分子机制和潜在治疗策略

**来源：** MedComm, 2025
**DOI：** 10.1002/mco2.70057
**类型：** 综合综述

### 核心发现
- 内皮细胞损伤是脓毒症、多器官功能障碍、心血管疾病等多种疾病的共同病理基础。
- 内皮屏障完整性的维持依赖于：糖萼、细胞间连接（VE-cadherin、occludin）、细胞骨架。
- 内皮细胞损伤导致：抗凝功能丧失、通透性增加、促炎状态、促血栓形成。

### 关键机制
- **糖萼破坏** → syndecan-1、硫酸乙酰肝素释放入血（ glycocalyx shedding）
- **VE-cadherin/occludin破坏** → 内皮通透性增加
- **内皮细胞凋亡/焦亡/铁死亡** → 内皮屏障完整性丧失
- **内皮-血小板-NETs相互作用** → 免疫血栓

### 对课题的启发
- syndecan-1（SDC-1）是糖萼降解的经典标志物，课题中可作为检测指标。
- 多条内皮细胞死亡途径中，铁死亡和焦亡是近年研究热点，课题机制探索可聚焦其一。
- 内皮保护治疗策略可作为课题治疗Arm设计参考（如糖萼修复、内皮修复）。
