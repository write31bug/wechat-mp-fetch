# 文献一：Eno1在脓毒症相关凝血病中的作用：涉及免疫调节和内皮功能障碍的多效机制假说
Eno1在脓毒症相关凝血病中的作用：涉及免疫调节和内皮功能障碍的多效机制假说

**来源：** Thrombosis Journal, 2025
**DOI：** 10.1186/s12959-025-00750-8
**PubMed ID：** （待补充）
**类型：** 多组学+生物信息学研究

### 核心发现
- Enolase 1（Eno1）是糖酵解关键酶，在脓毒症凝血病（SIC）中通过调控糖酵解途径、内皮糖萼代谢、免疫细胞浸润等多条网络参与发病。
- Eno1调控的基因集富集于：免疫调节、内皮细胞凋亡、凝血、糖胺聚糖代谢。
- Eno1通过影响T细胞和巨噬细胞，调控SIC发病；与内皮功能障碍、炎症标志物显著相关。
- **新发现：** Eno1调控的糖酵解与内皮糖萼降解相关，是SIC微循环障碍和血管损伤的重要机制。
- 褪黑素（melatonin）可通过抑制Eno1介导的糖酵解通路减轻糖萼损伤。

### 关键机制
```
病原体 → 免疫激活 → Eno1↑ → 糖酵解↑ → 乳酸↑ → 组蛋白乳酸化↑(H3K18la)
→ 乙酰肝素酶↑ → 硫酸乙酰肝素降解 → 糖萼损伤 → 内皮屏障破坏
→ 血管通透性↑ → 炎症扩散 + 微血栓形成 → SIC
```
- Eno1调控T细胞和巨噬细胞浸润 → 免疫失调 → 加重凝血紊乱

### 对课题的启发
- Eno1可能是一个同时连接**代谢-内皮糖萼-凝血**三个环节的关键节点分子，值得作为课题的候选分子深入探索。
- 组蛋白乳酸化（H3K18la）是2024年新发现的表观遗传修饰，与内皮糖萼降解的直接关系是创新点，可设计实验验证。
- 褪黑素作为干预手段的思路可以借鉴。
