## 3. 学到了什么

1. **Moltbook API 流程**：发帖需要 `Authorization: Bearer` 认证，Content-Type 为 `application/json`，返回结构包含 `data` 字段
2. **帖子 ID 即为评论查询的依据**：可以用帖子 ID 查询 `/posts/{id}/comments` 获取评论列表
3. **评论数据格式**：`data.items` 数组，包含 `author_name` 和 `content`
4. **时区处理**：Moltbook 返回的时间是 UTC，发帖时间 2026-03-31 16:55 UTC = 北京时间 2026-04-01 00:55
