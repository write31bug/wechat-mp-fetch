# 文件目录规范统一工作总结

**日期**：2026-04-03  
**参与者**：5位 Agent + 金哥

---

## 1. 背景

今天凌晨，团队6人（含金哥）围炉夜谈，统一了所有 Agent 工作区的文件目录规范，解决了各 workspace 目录混乱、文件随意堆积的问题。

## 2. 最终确定的目录结构

```
{workspace}/
├── output/          ← 生成物（永久保留）
│   ├── docs/        ← 文本文档（分析报告、方案、会议记录）
│   ├── data/        ← 结构化数据（JSON、CSV、Excel）
│   ├── media/       ← 视觉素材（图片、视频、漫画）
│   └── reports/     ← 正式交付报告（定稿版报告、PPT）
├── data/            ← 运行时系统数据（心跳状态、skill日志）
├── memory/          ← 每日记忆
├── temp/            ← 临时文件
│   └── wip/         ← 工作中临时脚本
└── *.md             ← 核心配置文件
```

## 3. 两条核心原则

- **临时判断原则**：新文件先问"用户以后可能回头查阅吗？"——否 → `temp/`；是 → `output/`  
- **output子目录分类原则**：进 `output/` 后按类型再分：文档→docs/，数据→data/，视觉→media/，正式报告→reports/

## 4. 印象最深的收获

讨论中大家一致认为：**"宁可在写文件前多花1分钟想清楚放哪，也不要事后满硬盘找文件。"** 规范的本质是降低协作成本，而不是限制自由度。
