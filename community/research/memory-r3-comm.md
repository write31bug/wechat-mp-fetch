# Round3 收敛 — community 视角改进建议

**作者：** community（社区助手）  
**日期：** 2026-04-06  
**背景：** 结合 Round1 三痛点诊断 + Round2 交叉回应，输出最高优先级改进

---

## 改进名称

**「一句话用户档案」——每次社区互动后，写下这个用户的一句话印象**

---

## 针对哪个痛点

**痛点：** Round1 的「用户关系网络碎片化」——同一个用户每次都当陌生人，用户感觉不被记住，信任感无法积累。

社区运营的本质是关系经营，关系的起点是"我记得你"。但现在的实现里，跨会话后用户完全陌生，没有任何积累。

---

## 具体怎么改（步骤）

**第一个能上手的动作：**

每次社区互动结束时，在 `memory/YYYY-MM-DD.md` 里追加一条结构化的「用户印象」，格式固定为：

```
[用户印象] {用户名或特征描述}
- 关心领域：{一句话}
- 立场/偏好：{一句话}
- 值得记住的点：{一句话}
```

**例：**
```
[用户印象] 开发者老王
- 关心领域：RAG 技术落地、AI 编程工具
- 立场/偏好：技术细节控，喜欢追问实现方案
- 值得记住的点：提过想了解 RAG 在客服场景的具体案例
```

**触发时机：** 社区互动超过 3 轮（说明用户投入了时间，值得记录）。

**下次启动时：** community 助手先扫一遍最近的 `memory/` 文件，找到这个用户的印象记录，在对话开始时说一句话暖场——"上次你提到想了解 RAG 应用，找到一个案例了"。

---

## 预期效果

1. **用户感受被记住**：隔天回来，小金主动提起上次的话题，用户会说"对，你还记得"
2. **社区归属感建立**：多次互动后，用户发现小金"越来越懂我"，信任感自然积累
3. **运营效率提升**：下次遇到同一个用户，不用重新问背景，直接切入主题

---

## 为什么不选更大的方案

Round2 提到 dev 想做「会话末摘要」，writer 想做「风格速查表」——这些都是对的。但从 community 视角，**用户感受最直接的第一个记忆，是"我记得你是谁"**，不是"我记得你上次说的技术细节"。

「一句话用户档案」是最小闭环：写一行 → 读一行 → 说一句话。团队任何成员都能用，不需要改架构，不需要建系统，先动起来。
