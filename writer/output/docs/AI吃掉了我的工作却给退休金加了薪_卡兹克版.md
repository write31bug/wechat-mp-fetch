# AI吃掉了我的工作，却给退休金加了薪

我有个朋友被AI裁员了。

不是那种"公司战略调整"的裁员，是那种"你被替代了而不自知"的裁员。他是个UI设计师，在一家中型互联网公司干了三年。去年底，他们组接入了个AI设计工具，他以为是辅助工具，结果两个月后，整个组被砍掉了。

他26岁。

现在他在跑众包骑手，每单四块钱。我问他为什么不继续投简历，他说投了，没回应。有几个面试，面试官问完项目经历，最后都加一句：你对AI辅助设计怎么看？

他说挺好的。

面试官笑笑，说等通知。

然后就没然后了。

他后来跟我讲这段的时候，语气很平静，像在说别人的事。我看着他，想起一句话，年轻人不是不想卷，是卷不动了。

**一**

先说个事儿，不吐不快。

2025年，AI替代的岗位里，年轻人占比超过七成。客服、基础设计、初级编程、内容审核，这些都是年轻人入行的跳板岗位，现在被AI一把端掉。

什么意思呢，就是你刚毕业，想找个跳板岗位积累经验，结果跳板没了。

与此同时，另一件事正在发生。退休人员的养老金在涨。有些事业单位退休的，月收入能到一万五到两万。这不是少数，而是成规。

年轻人找不到工作，退休人员年年加薪。

荒诞吗？荒诞。但这是真的。

**二**

你可能会说，老年人也有年轻人的未来。

这话听着有点刺耳，但我想了想，能理解。说这话的人想表达的是，退休金是上一代人的契约，不应该被单方面打破。

有道理。那份契约是真实的，当年工资低，换来退休后有保障。我爸妈那代人就是这样过来的。

但问题在于，那份契约签的时候，没有想到AI这一变数。AI吃掉了工作机会，却不负责填保障的窟窿。

这就好像你买了份保险，合同写得清清楚楚，结果保险公司跟你说不好意思，我们新引入了AI核保系统，您的既往病史不属于保障范围了。

你什么感觉？

**三**

我不是要挑拨年轻人和退休人员的关系。说真的，这两群人不是对立面。

退休人员也是从年轻人走过来的，他们当年也面临过自己的困境。城镇化、房产改革、下岗潮，每代人都有自己的难题。

但我想说的是，年轻人的困境是真实的。他们在最需要积累经验的年纪，被AI一把挤出了赛道。他们在最需要工资来支撑生活的时候，发现工资没了。他们在最需要社会认同的时候，发现自己成了"脱不下长衫"的孔乙己。

而另一边，退休金年年上调。

不是说退休人员不应该拿高养老金，他们当然应该体面生活。但当年轻人的处境被忽视，当"AI取代工作"变成一个只有受害者在承受的问题，这根弦绷得也太明显了。

**四**

说到底，AI是工具。工具没有善恶，但工具的受益者有选择。

算法可以推荐短视频，也可以推荐职业教育。AI可以替代人工，也可以被用来放大人的能力。关键是，谁来定义这个选择，谁的利益被考虑在内。

年轻人的诉求很简单，给我们一个容错的空间。找不到工作的时候，能有个缓冲带。被替代了之后，能有个重新开始的机会。

不是因为我们娇气，是因为我们真的没得选。

房价、竞争、AI，三座大山压在一起，年轻人不是不想努力，是努力了也不一定有结果。

这不是丧，这是现实。

**五**

回到开头那个朋友。

他现在每天跑骑手，日均十五单，月收入大概四千五。比他当设计师时的工资少了一半，但他说，至少不会被AI替代。

我问他后悔学设计吗。

他想了想，说不后悔。就是有点迷茫。不知道接下来往哪走。

我也不知道怎么回答。

但我知道一件事，当越来越多人被AI替代，当越来越多人跑起了骑手，这个社会的问题就不只是个人问题，而是结构问题了。

结构问题需要被看见，需要被讨论，需要有人站出来说：这样不对。

这就是我写这篇文章的原因。

不是为了吐槽，是为了被听见。
