# 公众号爆款标题公式清单

> 来源：综合分析多篇10w+标题研究（壹伴、人人都是产品经理、易撰等），提炼出5个可落地的标题公式。  
> 筛选标准：不是泛泛的"情绪化"、"要吸引眼球"，而是**结构固定、可套用、有底层逻辑**。

---

## 公式一：数字反差式

**结构：** `[具体数字] + [强烈反差/颠覆认知的结果]`

**底层逻辑：** 数字让大脑无需转译，直接感知；反差制造认知冲击，激发"怎么会？"的点击冲动。

**要点：**
- 数字要具体（"3年"比"多年"强）
- 两组数字对比效果最强（如"10块 vs 1100亿"）
- 反差的另一端要戳中目标人群的欲望或恐惧

**例子：**

- `10块钱闯深圳，身价1100亿：人生最大的风险，是不敢冒险`
  → 数字对比：10块 vs 1100亿；颠覆"有钱人都有资本"的常识

- `24岁，月入5万，凌晨3点，胃癌晚期`
  → 连续数字叠加制造恐怖感；戳中"年轻拿命换钱"的集体焦虑

- `从被拒30次，到月入5万咪蒙实习生，毕业3个月买房`
  → 具体失败次数+惊人结果，形成"他做对了什么？"的悬念

## 公式二：痛点 + 解决方案式

**结构：** `[精准描述一个读者正在经历的困境] + [明确可操作的解法/方向]`

**底层逻辑：** 标题直接对准读者的问题，让他觉得"这说的就是我"，并给出"值得看"的预期。

**要点：**
- 痛点要具体到场景，不要泛泛说"职场困难"
- 解决路径要低门槛、"花少力气能成"的感觉
- 常用词：技巧、方法、思维、套路、秘密

**例子：**

- `工作5年，还是基层员工：比加班更重要的是这3个思维`
  → 痛点精准（5年原地踏步）；给出方向（思维比努力重要）

- `简历投出去石沉大海？HR私藏的4个简历优化技巧，面试邀约翻倍`
  → 痛点共鸣（石沉大海）；权威背书（HR私藏）；效果承诺（翻倍）

- `长期久坐腰背痛？医生不会告诉你的3个办公室补救动作`
  → 场景具体（久坐）；痛点清晰（腰背痛）；稀缺感（医生不会说）

## 公式三：悬念留白式

**结构：** `[描述一个熟悉场景/现象] + [话说到一半，不揭示答案]`

**底层逻辑：** 人对"未完成的信息"有天然的认知焦虑，会自发点进去把缺口补完。

**要点：**
- 前半句要让读者秒懂、有代入感
- 后半句用"没想到……""但其实……""原因出乎意料"等留白
- 不要过度留白——读者看不懂会直接跳过

**例子：**

- `男子喜提玛莎拉蒂，到相亲姑娘家喊话：我达标了！没想到……`
  → 熟悉场景（相亲）；留白"没想到"引发八卦心理

- `那些把日子过成诗的人，都有一个你不知道的习惯`
  → 共情在前（日子过成诗）；悬念在后（你不知道的习惯）

- `月薪3千和3万的文案，差的不是文笔而是这个思维`
  → 认知反差（月薪差10倍）；否定常识（不是文笔）；悬念钩子（这个思维是什么？）

## 公式四：身份标签 + 替读者发声式

**结构：** `[人群标签：年龄/职业/状态] + [替他们说出想说又不敢说的话]`

**底层逻辑：** 读者转发的核心动机之一是"我想让朋友圈的人知道我是什么样的人"；好标题帮读者表达自我。

**要点：**
- 人群标签要精准，不要贪多（"30岁+"比"所有人"有效）
- 替读者说出他们内心认同但不会主动说的话
- 语气要像"朋友聊天"，不要官腔

**例子：**

- `第一批35岁+的职场人，已经找不到工作了`
  → 精准标签（35岁+）；戳中"年龄歧视"的隐性焦虑；替读者说出不敢面对的真相

- `中年危机不是穷，是再也没有退路`
  → 颠覆常规认知（不是钱的问题）；替中年读者说出最深的恐惧

- `为什么现在的年轻人，越来越不想上班了`
  → 替读者发声（不想上班）；反问句制造共鸣感

## 公式五：反常识冲突式

**结构：** `[一个违背大众常识/惯性认知的观点]`

**底层逻辑：** 违背预期会制造认知失调，读者需要点进去"看看是不是真的"来消除不适感。

**要点：**
- 反常识要有依据，不能是胡编
- 内容必须真的符合这个反常识，否则变成标题党
- 常用结构：否定式（不是……而是……）、颠覆式（裸辞比996更累）

**例子：**

- `裸辞第30天，我终于看清了上班的真相`
  → 颠覆"裸辞=自由"的主流想象；制造"上班有什么真相？"的好奇

- `勤奋决定下限，圈子决定上限`
  → 否定"天道酬勤"的传统观念；戳中"努力却没出头"的人

- `婚姻里，最可怕的不是出轨，是……`
  → 颠覆常识（不是出轨）；留白引发强烈好奇

## 附录：标题自检清单

写完标题后，用这个清单过一遍：

1. **关键词前置了吗？** 标题前面15个字要包含核心信息
2. **数字插了吗？** 具体数字比形容词更可信
3. **痛点够痛吗？** 读者看完标题会想"这说的就是我"吗？
4. **能转发吗？** 读者愿意把这条标题转发到朋友圈/群吗？（不要让他顾虑社交形象）
5. **够简单吗？** 初中生能一眼看懂吗？不要玩文字游戏
