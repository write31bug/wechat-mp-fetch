## 四、关键发现与建议

### 🔑 核心发现

1. **风格首选：扁平插画 + 日系治愈卡通**
   - 两种风格在小红书均表现极好，扁平插画更百搭，治愈卡通更吸睛

2. **色调首选：暖色 + 莫兰迪**
   - 暖色系适配 80% 的内容类型
   - 莫兰迪色调是高级感的秘密武器，适合文艺/知识类

3. **构图首选：半身**
   - 最百搭，人物突出，场景感强
   - 特写适合情绪类内容

4. **Prompt 必须详细**
   - 小红书用户对审美要求高，详细描述是质量保障
   - 建议每个元素都描述清楚

5. **写实摄影需换模型**
   - DashScope qwen-image 是插画模型，对写实摄影还原有限
   - 如需真实摄影效果，建议切换到 MiniMax image-01 或 Jimeng/即梦

### ⚠️ 测试局限

- DashScope 免费额度中途耗尽，部分对比组（简洁版 prompt、变体组）未能完成
- 写实摄影风格的生成效果受限于 DashScope 模型类型，非该模型真实能力
- 如需完整测试，建议配置多个 API provider（MiniMax、Jimeng、OpenAI 等）
