# 玩虾🦐几天小结

最近半个月我深度被 OpenClaw 玩了，上瘾了。

---

## 我到底建了个啥

### 一个「小金 + 四小弟」的班子

**小金**是我的调度中枢，接收我的指令，判断该谁上，然后把活派下去，最后汇总给我。

四个小弟各有所长：

- **💻 dev**：写代码、排查 Bug、做技术选型、研究工具链
- **✍️ writer**：写公众号文章、做小红书图、适配抖音字幕
- **📊 finance**：分析持仓、监控行情、给资产配置建议
- **🌐 community**：运营社区、分发内容、跟用户互动

听起来挺唬人的，其实本质就是**分工**——把不同类型的事交给专业的人去干。只不过这里"人"是 AI Agent。

---

## 这个团队能干嘛：真实场景举例

光说分工没意思，说几个我实际用过的场景：

**场景 1：讨论话题**
我提出一个话题，让他们从各自的领域去 talk，我就能从不同角度去看待一个问题。

> 比如我想讨论"要不要配置黄金"，dev 会从通胀角度分析，finance 会从持仓结构分析，community 会从用户关注点出发——同一个问题，三种视角，比我自己想全面多了。

**场景 2：想不出啥有用的了**

原本想法：以为多个 Agent 能像真人团队一样协作搞定复杂任务。现在发现——场景没有想象中复杂，但**记忆隔离 + 技能隔离**这个设计是真的香。每个 Agent 只看自己该看的东西，不会互相干扰，干净。

## 我写了 3 个 Skill

我自己写了 3 个 Skill，来帮助我：

### ✅ wechat-mp-fetch（公众号文章抓取）
**状态：完工了，正式跑着。**

丢一个公众号文章链接给它，它用 Playwright 渲染页面，把标题、正文、原始 URL 全抓回来。丢给 writer 直接改写，整个流程通了。

**解决了什么问题**：公众号文章不能直接转 markdown，这个工具填了坑。

### 🔧 multi-discussion（多 Agent 异步讨论）
**状态：半成品，核心逻辑有了，界面还没完善。**

我想要的是——抛一个话题，让 dev / writer / finance / community各自独立分析，然后汇总到一个结论。目前 Python 数据层和上下文构建都跑通了，但并行发言模式和总结呈现还在调。

**卡在哪**：多 agent 状态同步和发言顺序控制，比想象中复杂。

### 🔧 stock-technical-analysis（股票技术分析）
**状态：半成品，数据接口通了，分析逻辑还没串起来。**

想给 finance 装一个技术分析工具——MACD/KDJ/RSI 这些指标自动算，支持自选股。结果数据源接上了，指标也能量化输出，但怎么把多个指标串成一个"可操作建议"还没调通。

**卡在哪**：指标计算是工程问题，但"多个指标打架时怎么决策"是经验问题，还在想怎么表达。

> 写 Skill 这件事比想象中难。**完工的那个最有成就感，半成品的那两个才是真实状态——知道路在哪，但还没走完。**

## 我遇到的问题

**坑 1：subagent 会话越来越多**

- **怎么发现**：用了几天发现 sessions 列表越来越长，某些 subagent 已经结束了但 session 还留着。
- **怎么解决**：写了个定时脚本（每小时执行一次），自动清理超过 2 小时的 subagent session。
- **经验**：**session 是状态累积的单位，不用了就清，别等它膨胀。**

**坑 2：多微信接入**

- **怎么发现**：想同时在两个微信账号上跑 OpenClaw，发现消息互相串。
- **怎么解决**：通过 Gateway 配置不同 channel 账号，用 thread 机制隔离会话。
- **经验**：**多账号隔离要做好，不然信息串台很麻烦。**

**坑 3：多飞书接入**

- **怎么发现**：飞书多个群、多个机器人，想让不同群看到不同的 Agent 反应。
- **怎么解决**：按群配置不同的 agent 规则，飞书群和 OpenClaw 的绑定关系要清晰。
- **经验**：**平台账号和 Agent 的映射关系要提前理清楚。**

**坑 4：生成文件存放路径的问题**

- **怎么发现**：让 writer 输出文件，结果不知道跑去了哪里，桌面上找不到。
- **怎么解决**：搭了输出规范——`output/docs/`（文档）、`output/media/`（图片视频）、`temp/wip/`（临时），生成时直接指定路径。
- **经验**：**输出路径要提前定好规范，不能让 Agent 随便放。**

还有好多问题未曾解决：飞书群怎么互相聊天；多 Agent 互相沟通能看到上下文的 skill 没实现；Agent 怎么自己成长总结 等等
