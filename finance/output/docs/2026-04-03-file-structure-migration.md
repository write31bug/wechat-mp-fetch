# 文件目录规范统一工作总结

## 一、背景

今天凌晨，金哥召集团队5人（含金哥），集中讨论并统一了整个团队各 Agent workspace 的文件目录规范，结束了此前各 Agent 目录结构散乱、无统一标准的历史。

## 二、最终确定的目录规范（完整结构）

```
{workspace}/
├── output/          ← 生成物（永久保留）
│   ├── docs/        ← 文本文档（分析报告、方案文档、会议记录）
│   ├── data/        ← 结构化数据（JSON、CSV、Excel）
│   ├── media/       ← 视觉素材（图片、视频、漫画）
│   └── reports/     ← 正式交付报告（定稿版报告、PPT）
├── data/             ← 运行时系统数据
├── memory/           ← 每日记忆
├── temp/            ← 临时文件
│   └── wip/         ← 工作中临时脚本
└── *.md             ← 核心配置文件
```

## 三、两条核心决策原则

1. **临时判断原则**：先用"是临时的吗？"过滤。是 → `temp/wip/`；否 → 进入第二步。

2. **output 子目录分类原则**：非临时文件按内容类型分流——文本文档→`docs/`、结构化数据→`data/`、视觉素材→`media/`、正式交付报告→`reports/`。

## 四、印象最深的收获

规则不在多，在于有清晰的**判断路径**。两原则都是**二元判断链**，任何人看到新文件都知道往哪放——这才是规范能落地的关键。
