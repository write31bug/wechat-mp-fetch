# 微信公众号文章抓取技术方案

> 研究时间：2026-04-04
> 状态：方案已验证，工具已封装（待集成）

---

## 1. 背景

需要从微信公众号文章链接（`mp.weixin.qq.com/s/xxx`）提取正文内容，存入 Obsidian 或其他笔记系统。

---

## 2. 核心问题

微信公众号的文章内容是**客户端 JavaScript 动态渲染**的，直接 HTTP 请求只能拿到 HTML 壳，正文在 `#js_content` 容器里是空的。

| 方式 | 能拿到正文？ |
|------|------------|
| 直接 GET 请求 | ❌ 不能 |
| 浏览器自动化（Puppeteer/Playwright） | ✅ 可以 |
| 第三方渲染 API | ✅ 可以 |
| 搜狗搜索入口 | ⚠️ 部分可以 |

---

## 3. 技术方案：Playwright 浏览器渲染

### 原理

```
微信文章 URL
  ↓
Playwright 启动 Chromium（headless）
  ↓
页面加载，执行 JS 渲染
  ↓
等待 #js_content 容器内容出现
  ↓
提取正文 innerText
  ↓
转 Markdown 保存
```

### 关键技术点

1. **等待策略**：不能只等 `networkidle`，微信公众号有异步请求
2. **等 `#js_content` 出现**：用 `waitForSelector('#js_content', { timeout: 15000 })`
3. **检测重定向**：微信文章会重定向，等 URL 稳定后再提取
4. **图片处理**：微信公众号图片用 `data-src`（懒加载），不是 `src`

### CSS 选择器

| 内容 | 选择器 |
|------|--------|
| 文章标题 | `h2.rich_media_title` / `#activity_name` / `meta[property="og:title"]` |
| 文章正文 | `#js_content` |
| 图片 | `img[data-src]` |

## 8. 代码片段：核心抓取逻辑

```typescript
const { chromium } = require('playwright');

async function fetchWechatArticle(url) {
  const browser = await chromium.launch({ headless: true });
  const page = await browser.newPage();

  await page.goto(url, { timeout: 30000 });

  // 等重定向完成 + 内容出现
  await page.waitForFunction(() =>
    !document.URL.includes('login') && document.readyState === 'complete'
  );
  await page.waitForSelector('#js_content', { timeout: 15000 });

  // 取标题
  const title = await page.evaluate(() => {
    const el = document.querySelector('h2.rich_media_title') ||
                document.querySelector('#activity_name');
    return el ? el.textContent.trim() : '';
  });

  // 取正文
  const contentEl = await page.$('#js_content');
  const plainText = (await contentEl.innerText()).trim();

  await browser.close();
  return { title, content: plainText, url: page.url() };
}
```
