## 1. 需求概述

在 get-rich-slowly 项目中新增「基本面分析」页面：

1. **导入**：支持导入 `汇总持仓.xlsx` 数据，解析出股票/ETF 代码列表
2. **分析**：对导入的 A 股 ETF 批量抓取数据，按 100 分制评分
3. **展示**：分析结果在页面内展示，支持表格刷新和详情查看
4. **存储**：分析结果存档，每天一份 JSON

---

## 2. 范围约定

- ✅ 只支持 A 股 ETF（代码为 6 位纯数字）
- ✅ 本地静态计算评分，不调用 AI 分析流程
- ✅ 存档功能，历史对比 UI 不在本次范围内
- ❌ 不支持美股
- ❌ 不支持主动基金的基本面评分

### 3.1 腾讯财经（价格 / 涨跌幅）✅ 已验证可用

```
GET https://push2.eastmoney.com/api/qt/stock/get?secid={1/0}.{code}&fields=f43,f44,f170,f57,f58,f116
```

| 字段 | 说明 | 换算 |
|------|------|------|
| f43 | 当前价 | ÷100 |
| f44 | 昨收价 | ÷100 |
| f170 | 涨跌幅 | ÷100（单位 %） |
| f57 | 证券代码 | — |
| f58 | 证券名称 | — |
| f116 | 市值（元） | — |
| f173 | 市盈率 PE | ETF 通常为 0 |
| f162 | 股息率 | ÷100（单位 %） |

- secid 规则：`1.{code}` = 上交所（6 开头），`0.{code}` = 深交所（0/3 开头）
- ETF 示例（医疗器械ETF汇添富 159797，深交所）：
  ```json
  { "f43": 754, "f44": 756, "f170": 245, "f57": "159797",
    "f58": "医疗器械ETF汇添富", "f116": 312901892.992 }
  ```
  → 价格 0.754元，涨幅 +2.45%

### 3.2 天天基金网（净值 / 分红）✅ 已验证可用

| 字段 | 说明 |
|------|------|

### 6.2 xlsx 解析

```typescript
import * as XLSX from 'xlsx'

const parseXlsx = (file: File): ImportedPosition[] => {
  const wb = XLSX.read(file)
  const ws = wb.Sheets[wb.SheetNames[0]]
  const rows = XLSX.utils.sheet_to_json(ws, { header: 1 }) as any[][]

  // header row index = 0
  return rows.slice(1).map(row => ({
    code: String(row[0]),           // 代码
    name: String(row[1]),            // 名称
    latestPrice: Number(row[16]),    // 最新价
    todayChange: Number(row[15]),    // 最新涨幅（%）
    change1M: Number(row[19]),       // 近1月涨幅
    change3M: Number(row[20]),       // 近3月涨幅
    change6M: Number(row[21]),       // 近6月涨幅
    change1Y: Number(row[22]),       // 近1年涨幅
  }))
}
```

### 6.3 解析后存储

存入 `src/data/importedPositions.ts`（模块级 ref，页面刷新不丢失，下次打开自动恢复）。

### 6.4 标的类型判断

```typescript
const getTickerType = (code: string): 'A-Share-ETF' | 'A-Share-Stock' | 'Unknown' => {
  if (!/^\d{6}$/.test(code)) return 'Unknown'
  // 1开头 / 5开头 = ETF；0/3开头 = 股票/ETF
  return code.startsWith('1') || code.startsWith('5') ? 'A-Share-ETF' : 'A-Share-Stock'
}

### 7.1 价格 / 涨跌幅（腾讯财经）

// 并发获取所有标的实时价格
const fetchAllPrices = async (codes: string[]): Promise<Record<string, PriceData>> => {
  const results = await Promise.allSettled(codes.map(async (code) => {
    const market = code.startsWith('6') ? '1' : '0'
    const secid = `${market}.${code}`
    const res = await fetch(`/api/qt/stock/get?secid=${secid}&fields=f43,f44,f170,f57,f58,f173`)
    const json = await res.json()
    const d = json.data
    return {
      code,
      price: d.f43 / 100,
      preClose: d.f44 / 100,
      change: d.f170 / 100,      // 单位 %
      pe: d.f173 / 100,          // 市盈率
      name: d.f58,
    }
  }))
  const map: Record<string, PriceData> = {}
  for (const r of results) {
    if (r.status === 'fulfilled') map[r.value.code] = r.value
  }
  return map
}
```

## 8. 评分引擎（ETF 专用 100 分制）

> ETF 无独立财务报表，改为基于「业绩表现 + 风险调整收益 + 估值」的综合评分。

### 8.1 评分维度

| 维度 | 权重 | 指标 |
|------|------|------|
| 业绩趋势 | 35 | 近1月/3月/6月/1年涨幅的加权趋势 |
| 风险调整收益 | 30 | 年化波动率（近1年）→ 夏普比替代 |
| 估值安全 | 20 | PE 历史分位（需指数 PE 数据，暂无则用 NA） |
| 资金稳定性 | 15 | 持仓天数越多越好（代表中长期持有） |

### 8.2 评分函数

```typescript
interface ETFScore {
  total: number            // 0-100
  rating: 'Exceptional' | 'Strong' | 'Acceptable' | 'Weak' | 'Avoid'
  confidence: 'High' | 'Medium' | 'Low'
  metrics: {
    trend: number         // 0-35
    riskAdjusted: number  // 0-30
    valuation: number     // 0-20
    holdingDays: number   // 0-15
  }
}

const scoreETF = (data: ETFRowData): ETFScore => {
  // 1. 业绩趋势（0-35）
  const w1 = 0.1, w3 = 0.2, w6 = 0.3, w1y = 0.4
  const trendScore = clamp(
    ((data.change1M * w1 + data.change3M * w3 +
      data.change6M * w6 + data.change1Y * w1y) + 20) * 0.875,  // 归一化到 0-35
    0, 35)

  // 2. 风险调整（0-30）：用近1年涨幅/波动率代替夏普比
  const vol = estimateVolatility(data)  // 基于多时间段涨跌幅标准差估算
  const riskScore = clamp((Math.abs(data.change1Y) / (vol + 0.01)) * 15, 0, 30)

  // 3. 估值（0-20）：PE < 历史中位数加分，> 过高PE减分；ETF PE=0时给基准分10
  const valuationScore = data.pe > 0
    ? clamp(20 - (data.pe - 15) * 0.5, 0, 20)
    : 10  // ETF 无 PE，给基准分

  // 4. 持仓天数（0-15）：持仓越久越好
  const holdingScore = clamp(data.holdingDays / 365 * 15, 0, 15)

  const total = clamp(trendScore + riskScore + valuationScore + holdingScore, 0, 100)
  const rating = total >= 85 ? 'Exceptional' : total >= 75 ? 'Strong'
               : total >= 65 ? 'Acceptable' : total >= 50 ? 'Weak' : 'Avoid'
  const confidence = data.pe > 0 ? 'High' : 'Medium'

  return { total, rating, confidence,
    metrics: { trend: trendScore, riskAdjusted: riskScore,
               valuation: valuationScore, holdingDays: holdingScore } }
}
```
