## 微信公众号文章抓取

### 核心结论
微信公众号文章是 **JS 动态渲染**，直接 HTTP 请求拿不到正文，必须用浏览器环境。

### 技术方案
使用 **Playwright**（Chromium headless）模拟浏览器访问：
1. `page.goto(url)` 加载页面
2. `waitForSelector('#js_content')` 等正文容器渲染
3. 提取 `#js_content` 的 `innerText`
4. 标题从 `h2.rich_media_title` 或 `#activity_name` 取

### 工具位置
```
E:\openclaw\dev\tools\wx-article-fetch.js
```

依赖：`playwright`（已安装在 `E:\openclaw\dev\node_modules`）

使用方式：
```bash
# CLI
node tools/wx-article-fetch.js <url>

# JSON 模式
node tools/wx-article-fetch.js <url> --json

# 保存文件
node tools/wx-article-fetch.js <url> --save
```
